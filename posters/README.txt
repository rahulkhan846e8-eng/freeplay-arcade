POSTERS FOLDER
==============

The site uses your real cover images as the game art on the cards and
posters. Drop each image in THIS folder, named EXACTLY like this:

  gta-iii.jpg     <- Grand Theft Auto III cover  (GAME 02 card + poster)
  gta-v.jpg       <- Grand Theft Auto V cover    (GAME 04 card + poster)
  minecraft.jpg   <- Minecraft cover             (GAME 05 card + poster)
  vice-city.jpg   <- Vice City cover             (GAME 06 card + poster)

Tip:
- Right-click each image you saved > Save As > type the name above.
- JPG or PNG both work; if you use PNG, change the filenames in the HTML
  (search for "posters/" to find the 6 <img> tags).

No cover yet (keeps the built-in drawn art — that is correct):
  GTA 2 (GAME 01) and GTA IV (GAME 03) use their stylized SVG art.

If an image is missing or misnamed, the site automatically falls back
to the built-in drawn art — nothing breaks.
